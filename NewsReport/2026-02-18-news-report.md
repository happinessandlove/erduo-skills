### 7. GPU 上的 Async/Await：Rust 异步并发移植到 GPU 硬件

**摘要**: VectorWare 成功将 Rust 的 Future trait 和 async/await 语法移植到 GPU 上运行，这是首个在 GPU 硬件上直接实现结构化并发抽象的实用方案。传统 GPU 编程依赖数据并行，复杂场景下的 warp 专门化需要手动同步管理，容易出错。该方案复用了 Rust 现有的 Future trait 和 Embassy 执行器（原为嵌入式系统设计），以最小修改即可在 GPU 上运行，实现了 CPU 和 GPU 代码的统一语法。

**要点**:
1. 首次在 GPU 上实现 Rust 的 async/await 结构化并发，解决了传统 GPU 编程中手动同步管理困难的问题
2. 复用 Rust 现有生态而非创建新语言，将嵌入式系统的 Embassy 执行器适配到 GPU，实现 CPU/GPU 代码统一
3. 存在协作式调度的权衡——GPU 缺乏中断机制需使用自旋循环，执行器开销增加寄存器压力，但换来了与现有 Rust 库的可组合性
